# V100 机器 WorkBuddy 训练提示词

> 把下面整段直接粘贴给 V100 机器上的 WorkBuddy，它就会自动完成环境准备、数据切分、训练、导出 ONNX 的全流程。

---

## 直接复制这段给 WorkBuddy

```
你现在在 V100 机器上，帮我训练一个语音唤醒词（KWS）模型。项目目录已经放在当前工作目录下的 kws 文件夹里。

请按以下步骤自动完成，每一步跑完把关键结果汇报给我，遇到报错把完整日志贴出来：

1. 确认环境：
   - 检查 Python 版本（建议 3.9~3.12），运行 `python --version`
   - 建议建独立虚拟环境：`python -m venv venv`，Windows 激活 `venv\Scripts\activate`

2. 安装依赖：
   `pip install -r kws/requirements.txt`
   - 如果 V100 有 CUDA，torch 建议装对应 CUDA 版（如 `pip install torch --index-url https://download.pytorch.org/whl/cu121`）
   - 模型极小（约 10 万参数），纯 CPU 也能几分钟跑完，不一定非要 GPU

3. 切分真录音（唤醒词是「你好高总」）：
   - 原始录音在 kws/raw/positive/ 下（m4a 格式）
   - 运行 `python kws/split_recordings.py`，会自动按静音切分成单条 wav 到 kws/data/positive/
   - 确认切出正样本条数（预期 50~70 条）

4. 负样本已就绪，跳过生成：
   - `kws/data/negative/` 已包含 205 条负样本（174 条 TTS 人声日常短语 + 31 条合成噪音）
   - 不需要再跑 generate_data.py，直接用现有负样本训练

5. 训练 + 导出 ONNX：
   `python kws/train.py --epochs 30`
   - 观察训练日志里的 val_acc（验证准确率），理想应 > 0.95
   - 产物在 kws/output/nexus_kws.onnx

6. 验证 ONNX：
   用 Python 快速验证产物有效（输入 mfcc 形状 [1,1,61,40]，输出 logits）：
   python -c "import onnx; m=onnx.load('kws/output/nexus_kws.onnx'); onnx.checker.check_model(m); print('OK')"

全部完成后，把 kws/output/nexus_kws.onnx 拷回 U 盘/共享给我，并告诉我最终的 val_acc 数值。

关键约束：
- 唤醒词是「你好高总」四个字，不要改
- 全流程本地离线，不要用任何云端 API
- 每一步必须先看实际运行输出再判断成败，不要只读代码猜测
```

---

## 注意事项（给你自己看）

1. **负样本**：当前只有合成负样本（噪音/音调/静音）。如果后续你补录了「日常话」的负样本录音，放进 `kws/raw/negative/`，再跑 `split_recordings.py` 会自动一起切分，精度会更好。

2. **真录音补充**：唤醒词模型越多人声样本越好。你以后想提升精度，就多录几段「你好高总」放进 `kws/raw/positive/`，重跑切分 + 训练即可。

3. **产物回传**：训练出的 `nexus_kws.onnx`（约 13KB）要拷回 Android 项目的 `app/src/main/assets/nexus_kws.onnx`，替换旧模型。

4. **环境差异**：如果 V100 机器是 Linux，虚拟环境激活命令是 `source venv/bin/activate`，其余命令一样。
